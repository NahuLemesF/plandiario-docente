# PlanDiario Docente

Aplicación web para planificación diaria docente.

## Objetivo

Permitir a docentes crear, editar y visualizar planificaciones diarias organizadas por fecha, área y metas pedagógicas.

## Estado del proyecto

🚧 MVP en desarrollo

## Arquitectura

- Clean Architecture
- Spring Boot (Backend)
- Persistencia relacional (a definir)
